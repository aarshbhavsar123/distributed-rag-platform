# 5. Core Workflow

# STEP 1 — User Uploads File

User uploads:

* PDF
* DOCX
* GitHub repo
* Text file

Upload Service stores metadata in PostgreSQL.

---

# STEP 2 — Kafka Event Triggered

Upload Service publishes event:

```json
{
  "documentId": "123",
  "userId": "456",
  "fileUrl": "..."
}
```

Topic:

```text id="wjpw1x"
document.uploaded
```

---

# STEP 3 — Embedding Worker Consumes Event

Python AI service:

* Downloads file
* Splits into chunks
* Generates embeddings

---

# STEP 4 — Store Embeddings

Embeddings stored in vector DB.

Metadata stored in PostgreSQL.

---

# STEP 5 — User Asks Question

Example:

> “Explain payment architecture”

---

# STEP 6 — RAG Pipeline Executes

```text id="g9j14u"
Question
   ↓
Embedding Generation
   ↓
Similarity Search
   ↓
Top Relevant Chunks
   ↓
LLM Prompt Construction
   ↓
AI Response
```
